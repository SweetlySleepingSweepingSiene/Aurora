# Aurora UI Prototype v1.0

Static interactive prototype packaged for GitHub Pages.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root (index.html must remain at the root).
3. In the repository, open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. GitHub will provide the public Pages URL after deployment.

No build step or backend is required for this prototype.
